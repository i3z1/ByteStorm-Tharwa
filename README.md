# ثَروة (Tharwa) — مساعد بنكي ذكي 🏦🤖

> **فريق ByteStorm** — هاكاثون امد 2026، أكاديمية طويق · مسار: الذكاء الاصطناعي التوليدي للتقنية المالية

مساعد بنكي توليدي يعمل داخل التطبيق البنكي: نفّذ التحويلات، وحلّل مصروفاتك، واحصل على توصيات استثمار — كلها **بأوامر طبيعية بالمحادثة**. يحوّل «ثَروة» اللغة الطبيعية إلى عمليات بنكية فعلية عبر **Function-Calling**.

## 🔗 النموذج التفاعلي المباشر
**جرّبه الآن:** https://tharwa-orcin.vercel.app

افتح شاشة «المساعد» من الشريط السفلي، ثم اكتب مثلاً:
- `حوّل 500 لأحمد` → يفهم الأمر، يطلب التأكيد، ثم **ينفّذ التحويل فعلياً** (ينقص الرصيد وتظهر العملية).
- `كم صرفت على المطاعم؟` أو `كم دفعت في العثيم؟` → يجيب بأرقام حقيقية من بيانات ومعاملات العميل.
- `أبي أجمع 30 ألف لسيارة خلال سنة` → يحسب القسط الشهري المطلوب بعائد مركّب ويفتح شاشة الاستثمار بخطة توصلك للهدف.
- `احسب زكاتي` → بطاقة بزكاة رصيدك التقديرية (2.5%).
- `حط ميزانية 1500 للمطاعم` → حد صرف بشريط تقدم في شاشة التحليل.
- `قيّم وضعي المالي` → تحليل نسبة الادخار ونصائح عملية من أرقامك الفعلية.
- أو **اضغط زر المايك وتكلّم** — يتحوّل كلامك إلى نص تراجعه ثم ترسله (وفعّل زر السماعة إذا تبي ردوداً صوتية).

## ✨ المزايا
- **تحويلات بالمحادثة** — أمر طبيعي واحد + خطوة تأكيد آمنة.
- **أوامر صوتية بالعربية** — تحدّث مع مساعدك البنكي وراجع النص قبل الإرسال؛ الرد الصوتي خيار يُفعّل من زر السماعة (Web Speech API) — شمول مالي لكبار السن وضعاف البصر.
- **حماية ذكية من الاحتيال** — تنبيه أمان تلقائي داخل بطاقة التأكيد عند أي تحويل بمبلغ غير معتاد.
- **إيصال قابل للمشاركة** — بعد كل تحويل يظهر إيصال برقم مرجعي وزر مشاركة، أو اطلبه: «أبي إيصال آخر تحويل».
- **استثمار مرتبط بهدف** — يحسب القسط الشهري المطلوب لهدفك بعائد مركّب، ويتحقق أنه ضمن فائضك الشهري (الدخل − المصروفات).
- **زكاة تقديرية** — حاسبة زكاة (2.5% من الرصيد) ببطاقة واضحة.
- **ميزانيات ذكية** — حدود صرف بالفئات مع أشرطة تقدم وتنبيه عند التجاوز.
- **مستشار مالي شخصي** — تقييم الوضع المالي ونصائح من أرقام العميل الفعلية (شمول مالي حقيقي لكل عميل).

## 🧠 كيف يعمل (البنية)
```
واجهة التطبيق (HTML/JS)  ──►  /api/chat (Vercel Serverless)  ──►  Gemini (LLM) + Tools
        ▲                                                              │
        └──────────  رد + تحديث الحالة + تنفيذ الأداة  ◄───────────────┘
```
- يفهم نموذج **Google Gemini** أمر العميل بالعربية، ويستدعي الأداة المناسبة:
  - `execute_transfer(amount, recipient)` — ينفّذ التحويل بعد التأكيد.
  - `open_screen(screen)` — يفتح شاشة التحليل/الاستثمار.
- مفتاح الـ API محفوظ **كسر على الخادم** (`GEMINI_API_KEY`) ولا يظهر إطلاقاً في المتصفح.
