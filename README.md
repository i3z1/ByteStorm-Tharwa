# ثَروة (Tharwa) — المساعد المصرفي الذكي 🏦🤖

> **فريق ByteStorm** — هاكاثون أمد 2026، أكاديمية طويق · مسار: الذكاء الاصطناعي التوليدي للتقنية المالية

مساعد بنكي توليدي **يُدمج داخل تطبيق البنك نفسه** (وحدة White-label): يفهم اللهجة السعودية كتابةً وصوتاً، وينفّذ **14 عملية بنكية فعلية** عبر **Function-Calling** — تحويلات، تجميد بطاقات، ادخار مرابحة، تقدير تمويل، زكاة، ميزانيات، وأكثر.

**المبدأ المعماري:** الذكاء يقترح، والكود الحتمي على الخادم يتحقق وينفّذ، والعميل يقرر — النموذج اللغوي لا يملك التنفيذ أبداً.

افتح شاشة «المساعد» واكتب — أو اضغط المايك وتكلّم:
- `حوّل 500 لأحمد العتيبي` → بطاقة تأكيد → **رمز تحقق OTP** → تنفيذ فعلي + إيصال يُشارك أو يُحفظ PDF
- `ضاعت بطاقتي!` → **تجميد فوري خلال ثوانٍ** ترفض بعده كل العمليات + عرض بطاقة بديلة
- `كم يطلع لي تمويل شخصي؟` → تقدير مرابحة من دخلك الفعلي (ضمن حد استقطاع 33%) — وللتقديم الرسمي تُفتح **تذكرة موثّقة لموظف**
- `وش أفضل بطاقة لي؟` → ترشيح من نمط صرفك الفعلي (نسبة تطابق + عائد متوقع) وإصدار رقمي فوري
- `أبي أجمع 30 ألف لسيارة خلال سنة` → خطة **ادخار مرابحة** بقسط محسوب بعائد مركّب ضمن فائضك
- `قيّم وضعي المالي` → درجة من 100 بمعادلة معلنة (ادخار 45 + ميزانيات 30 + توازن 25)
- `احسب زكاتي` · `حط ميزانية 1500 للمطاعم` · `وش رسوم التحويل؟` (خط الدعم الأول يجيب فوراً)

## 🛡️ الأمان — أربع طبقات
1. **النموذج يقترح ولا يملك** — التنفيذ كود حتمي على الخادم؛ `execute_transfer` يرفض برمجياً أي تنفيذ بدون اقتراح مؤكَّد، حتى لو حاول النموذج أو المستخدم تجاوز التأكيد (مقاوم لحقن الأوامر).
2. **موافقة بشرية موثّقة** — بطاقة تأكيد + رمز تحقق لأي عملية مالية، ودرع احتيال ينبّه على المبالغ غير المعتادة (≥5,000 ر.س أو >40% من الرصيد).
3. **تقليل البيانات وتعقيمها** — حالة العميل تُعاد بناؤها وتُقيَّد على الخادم؛ المفتاح السرّي لا يصل للمتصفح أبداً.
4. **تسليم ذكي للبشر** — ما يحتاج موظفاً (تقديم تمويل، فتح حساب، شكوى معقدة) يتحول **تذكرة برقم مرجعي**، لا اعتذاراً نصياً. الذكاء يعرف حدوده.

## 🧠 كيف يعمل (البنية)
```
واجهة التطبيق (HTML/JS · PWA · RTL)  ──►  /api/chat (Vercel Serverless)  ──►  Gemini + 14 Tools
        ▲                                        │ تحقق حتمي: آيبان، رصيد، حدود، درع احتيال
        └────────  رد + حالة محدثة + بطاقات تفاعلية  ◄────────┘
```
- **الحسابات المالية كلها حتمية بالكود** (عائد مركّب، درجة الصحة، أهلية التمويل) — النموذج يشرح النتيجة ولا يخترعها.
- **سلسلة نماذج احتياطية** عند الضغط (429/503) + **ردود مضمونة** بعد كل تنفيذ — العرض لا يتعطل أبداً.
- **صوت ثنائي الاتجاه:** Web Speech API (ar-SA) للأوامر + Gemini TTS بردود منطوقة متدفقة.
- مفتاح الـAPI سرّ على الخادم (`GEMINI_API_KEY`) ولا يظهر إطلاقاً في المتصفح.
